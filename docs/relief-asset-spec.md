# 浮雕资源交付规范

本文说明设计需要交付什么文件，才能直接替换项目里的浮雕。规格对照原站 `reliefs_high_compressed.glb` 的实测结构整理。

## 1. 交付清单

| 文件 | 内容 | 必需 |
| --- | --- | --- |
| `reliefs.glb` | 全部浮雕分块（几何 + 每块 2 张烘焙贴图） | 是 |
| `plaster.jpg` | 石膏墙面纹理，1024×1024，灰度，可无缝平铺 | 是 |
| `mask-noise.png` | 斑驳噪声，1024×1024，灰度，可无缝平铺；用来让鼠标挤出的边缘不规则 | 是 |
| `reliefs_low.glb` | 低配版：贴图 1024²、面数减半，给移动端用 | 可选 |
| `source.blend` | 工程源文件，方便后续修改和重新烘焙 | 建议 |

收到文件后放进 `public/assets/relief/`，再改 `src/config.ts` 里的 `assets` 指向它们即可，不需要改代码。

## 2. 坐标与单位

- 1 个单位 = Blender 里的 1 m。
- 墙面在 glTF 的 XY 平面上，浮雕朝 +Z（朝向观众）凸出。在 Blender 里用默认的 "+Y Up" 导出时，对应的是：正视图里墙面在 XZ 平面，浮雕朝 −Y 凸出。
- 相机在 z = 15 处，视场角 30°，一屏大约能看到 13 × 8 个单位。

## 3. 分块排布

浮雕被切成若干分块，排成 **3 列 × N 行**（原站是 6 行，共 18 块），滚动时按行无限循环。

| 项 | 原站数值 | 说明 |
| --- | --- | --- |
| 列中心 x | −13.25 / 0 / +13.25 | 窄屏只露中间一列，宽屏能看到两侧列的边缘 |
| 行中心 y | 0, −10, −20 … | 行距 9.995；如果改了行距，需要告诉开发改 `layout.rowHeight` |
| 单块尺寸 | 约 13.3 × 11.3 | 比行距略高，相邻行在边缘有重叠，衔接更自然 |
| 第一屏 | y = 0 那一行的中间列 | 打开页面先看到的就是它，放最好看的一块 |

要求：

- 每块是**场景根下的一个独立 mesh 对象**，不要做父子层级，也不要放空物体。
- 对象原点放在分块中心，用对象的位置来表示排布；导出前应用旋转和缩放（旋转 0，缩放 1）。
- 每块只用**一个材质**。
- 一块可以只覆盖半边：没有浮雕的地方，运行时会由背景墙补齐。
- 第 1 行的顶部要能和第 N 行的底部衔接（会循环），注意上下边缘的构图。

## 4. 网格

- z = 0 是墙面，浮雕的最高点不超过约 1.2（原站在 0.6–1.2 之间）。可以有少量负值（≥ −0.1），用来做墙面的凹陷。
- 每块控制在 5–7 万个顶点（原站高配 1.2 万–6.7 万）。导出时开启 **Draco 压缩**。
- 只需要 `POSITION` 和 `TEXCOORD_0`，**不要导出法线**，运行时不使用。
- **UV0 必须是展开后不重叠的贴图集**，因为它就是烘焙目标。原站的做法是：正面大块方形区域放墙面和浮雕正面，上边和右边的条带放侧面、底面等小岛。

## 5. 烘焙贴图（核心）

运行时会按鼠标划过的强度，在 6 个"长出程度"的光照结果之间插值，几何本身不参与打光。因此每块要烘焙 6 张灰度光照图 L0–L5：

| 级别 | 浮雕高度 | 说明 |
| --- | --- | --- |
| L0 | 0%（平墙） | 整张是墙面色，运行时实际不采样，但通道要填上 |
| L1 | 20% | |
| L2 | 40% | |
| L3 | 60% | |
| L4 | 80% | |
| L5 | 100% | 完全挤出的状态 |

做法：同一套 UV，把浮雕沿 Z 方向缩放到对应比例（用 Displace 修改器的强度，或 shape key），各烘焙一次。

打包规则（每块 2 张，各 2048×2048、8 位 RGB，WebP、PNG 或 JPG 都可以）：

| 贴图 | glTF 材质槽 | R | G | B |
| --- | --- | --- | --- | --- |
| `*_packed_01` | Base Color | L5 | L4 | L3 |
| `*_packed_02` | Emissive（emissive 强度 = 1） | L2 | L1 | L0 |

烘焙要求：

- **平墙的值必须正好是 139/255（0.545，sRGB）**。原站贴图里出现最多的像素值就是 139。这个值不准，鼠标划过时墙面会整体变亮或变暗，出现色块。
- 材质用纯白漫反射，**不要带石膏纹理**，石膏纹理在运行时叠加。
- 用 Cycles 烘焙 Combined 或 Diffuse，包含直接光、阴影和环境光遮蔽。全部分块用**同一盏灯、同一个方向**（原站的光大致从左上方来，阴影比较长），6 级之间也不能改灯光。
- 采样数要足，开降噪，避免出现颗粒感。
- 贴图边缘留 8–16 px 的 margin，避免 mipmap 时出现接缝。

## 6. 石膏纹理和噪声

- `plaster.jpg`：亮度在 0.85–1.0 之间的细微斑驳加浅色细纹，用 G 通道。背景墙按"一屏一张"平铺，浮雕分块按"10 个单位一张"平铺，所以必须四方连续。
- `mask-noise.png`：中等频率、成块的灰度噪声，用 G 通道，四方连续。

## 7. 自查清单（交付前）

- [ ] 在 Blender 里重新导入 glb：分块都在场景根下，每块一个材质，Base Color 和 Emissive 都有贴图。
- [ ] 用取色器检查任意平墙处：R、G、B 都是 139。
- [ ] 6 级从 L0 到 L5 阴影逐级变长，没有跳变。
- [ ] 相邻分块的接缝处，光照方向和亮度一致。
- [ ] 放进项目运行，鼠标划过时，浮雕的长出和退回之间没有闪烁或色块。
